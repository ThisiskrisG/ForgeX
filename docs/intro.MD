# Intro

Welcome to ForgeX (KristonIde).

ForgeX is a lightweight, web-first integrated development environment (IDE) prototype built using modern web technologies. These documentation pages are arranged in a simple, linear "page-turn" order so users can read through setup, architecture, and developer guidance step-by-step.

What you'll find in this documentation:

- A short, actionable Technology Stack reference.
- Step-by-step developer setup and contribution guidelines.
- Project structure and notes to help you navigate the codebase.
