# ForgeX

ForgeX — lightweight web IDE (KristonIde) built with modern web technologies.

This repository now includes a paginated documentation set in docs/ that acts like a short book to guide contributors and users through the project.

Quick links
- Documentation (start here): docs/index.md
- GitHub Pages / site landing: index.md

Technology stack (short)
- HTML, CSS, JavaScript (ES2020+)
- Editor: Monaco Editor
- Build: Vite (recommended)
- CI: GitHub Actions
- License: Apache 2.0

How this integrates with IDEs
- Open this repo in VS Code or Codespaces and click docs/index.md to begin. The docs are organized with Prev / Next links for a page-turn experience.

Contributing
- See docs/03-Setup.md for steps to get started.
